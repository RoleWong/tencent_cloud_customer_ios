# **TencentCloudCustomer (Renamed)**

`TencentCloudCustomer` has been **renamed** to `TencentCloudAIDeskCustomer`.  
Please update your dependencies to continue receiving updates and support.

---

### 🚨 **Migration Guide**

1. **Update your `Podfile`**:
   ```ruby
   pod 'TencentCloudAIDeskCustomer'
   ```
2. **Run**:
   ```bash
   pod install
   ```

For more information, visit the new CocoaPods page:
